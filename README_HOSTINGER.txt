# UMA Pest Control Services — Hostinger Static Website

This is a complete self-contained static export of the current website.

## Hostinger deployment

1. Extract this ZIP.
2. Upload `index.html` and the complete `assets/` folder into Hostinger's `public_html` directory.
3. Keep the folder structure unchanged.
4. Open your domain; `index.html` is the homepage.

The website CSS and JavaScript are intentionally kept inline in `index.html` so the visual design and behavior remain identical. All images, video, poster artwork, and uploaded fonts are local files under `assets/`. WhatsApp, phone, email, and Google Maps links remain external by design.
